Drivon — Manual Test Guide

Phases 1–8: accounts and vehicles, fuel, services and expenses, documents, insights, reminders and notifications, Ask My Vehicle, and offline use. Every test is done in the app on your phone. Each one says exactly what to type and tap, and what you should see.

Expected numbers were checked by running this exact scenario against the API. Text in violet is shown by the app word for word. Example dates assume today is 11 Oct 2026; use your own dates.

Before you start

  1. API: start it from IntelliJ as usual, with the R2 variables (Phase 4), FIREBASE_SERVICE_ACCOUNT_BASE64 (Phase 6) and GEMINI_API_KEY / GROQ_API_KEY (Phase 7) set.
  2. Fresh install: on the phone, long-press the Drivon icon → Uninstall. Then run the app from Android Studio (with google-services.json in place and the phone connected as usual). A fresh install resets the notification permission and the data saved on the phone, so Phases 6 and 8 behave as described.
  3. Have ready: a sheet of paper to photograph, and a small PDF (under 5 MB) saved on the phone, for example a bill or ticket in Downloads.
  4. Use a new account (an email you have not registered before) so the numbers match. To repeat the guide later, change the email, for example nimal.drivon2@example.com.
  5. Run all tests in order and on the same day. Later tests build on earlier ones; dates are relative to today. Don't run Phase 5 in January (it compares last month with this year).
  6. Dates appear as 11 Oct 2026; months as October 2026. "Last month" means the calendar month before this one.
  7. Confirmation messages such as Fill-up logged appear briefly in a dark bar at the bottom (a snackbar). If two come quickly, the second waits for the first to fade.
How to read a test. Steps say what to do: Field → value means tap the field and type the value. Expected lists what must be true. Tick Pass or Fail and note anything odd.
Known issue — date pickers for future dates. The calendars for Next service date, Due date (optional), Issue date (optional) and Expiry date (optional) open far ahead (January 2100, next year or ten years ahead) instead of near today. The steps work around it: tap the month-and-year label at the top of the calendar (for example January 2100), choose this year in the list, and the calendar jumps back to the current month. Then tap the day (use the < > arrows for another month) and tap OK.

To come back online, plug the cable in and run the same adb reverse tcp:8080 tcp:8080 setup command again (it is removed whenever the phone disconnects).
