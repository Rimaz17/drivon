Drivon — Manual Test Guide

Phases 1–3: accounts and vehicles, fuel tracking, maintenance and expenses. Every test is done in the app on your phone. Each one lists exactly what to type and tap, and what you should see.

Expected values were checked against the API with this exact scenario. Text in violet is shown by the app word for word.

Before you start

  1. Start the API on your laptop and run the latest app build on your phone, as usual (see frontend/README.md).
  2. Use a new account (an email you have not registered before) so the numbers match this guide. If you repeat the guide, change the email, for example nimal.drivon2@example.com.
  3. Run the tests in order and on the same day. Later tests build on earlier ones, and dates are relative to today.
  4. Wherever the guide says today, the app shows today's date in the format 7 Oct 2026. Current month means the month name and year, for example October 2026.
  5. Confirmation messages such as Fill-up logged appear briefly in a dark bar at the bottom of the screen (a snackbar). If two come quickly, the second shows after the first fades, so wait a few seconds before checking it.
How to read a test. Steps say what to do: Field → value means tap the field and type the value. Expected lists what must be true. Tick Pass or Fail and note anything odd.

X.1Server not reachable

Steps
  1. Stop the API on your laptop. Close the app completely and open it again.
  2. Start the API again, wait until it is running, then tap Try again.
